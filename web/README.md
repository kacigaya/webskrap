# WebSkrap documentation site

This directory contains the Next.js site published at
<https://kacigaya.github.io/webskrap/>. It is a static export built with Bun
and deployed to GitHub Pages.

## Local development

Install [Bun](https://bun.sh/) and run:

```bash
cd web
bun install --frozen-lockfile
bun run dev
```

Open <http://localhost:3000>. The local server uses no base path by default.

## Project layout

- `content/` contains the Markdown documentation and frontmatter.
- `src/app/` contains the Next.js routes, layouts, metadata, and global CSS.
- `src/components/` contains site and UI components.
- `src/lib/docs-nav.ts` defines documentation navigation and static doc routes.
- `public/` contains files copied into the static export.

Add a Markdown page under `content/`, then add its route to
`src/lib/docs-nav.ts` when it should appear in navigation and be generated by
the docs catch-all route.

## Checks and static export

Run the same site checks used by GitHub Actions:

```bash
bun install --frozen-lockfile
bun audit
bun run lint
NEXT_PUBLIC_BASE_PATH=/webskrap bun run build
```

The production build writes the static site to `out/`. Set
`NEXT_PUBLIC_BASE_PATH` when serving the export below a subpath. GitHub Pages
uses `/webskrap`; a root-hosted deployment can leave it unset.

## Deployment

The [Pages workflow](../.github/workflows/pages.yml) builds and deploys the
site after a push to `main`, or when started manually. Repository Pages
settings must use GitHub Actions as the source. Do not commit `out/` or
`.next/`; both are generated and ignored.
